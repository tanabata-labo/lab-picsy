# link farm 対策の比較: η 正則化と予算の下限 ε（2026-11-24）

[最初の比較実験](2026-11-24-first-runs.md) で、論文どおりの計算（厳密モード）は link farm に弱いことが分かった。性質 P7（[spec.md](../spec.md) §5）はその静的な形で、予算0で組の外を評価しない組は吸収集合になる。ここでは対策を2つ比べる。

| | η 正則化（D4 の正則化モード） | 予算の下限 ε（D12 の案） |
|---|---|---|
| 何をするか | 貢献度を計算するときだけ $(1-\eta) E' + \eta J$ を使う | 取引で $E_{bb} - \alpha \geq \varepsilon$ を要求する（D5 を締める） |
| 論文の $c$ の定義 | 変える | 変えない |

## 設定

[最初の比較実験](2026-11-24-first-runs.md) と同じ（n=100、150エポック、1エポック = 取引100回＋自然回収1回、 $\gamma = 0.05$ ）。共謀者は予算を全額ではなく、 $\varepsilon$ を残して仲間へ払う。

- 再現: `cd python && uv run python scripts/exp_floor.py <farm|late|two|base|join>`。各エポックの記録は `runs/floor/*.csv`（git 対象外）
- 数値は最後の10エポックの平均。「占有」は共謀者の貢献度の合計を $N$ で割ったもの（10エポック目／50エポック目／最後）

### 共謀なし

$\varepsilon \in \lbrace 0.02, 0.05, 0.1, 0.2 \rbrace$ のどれでも、 $\varepsilon = 0$ と同じ結果になった（成立99.5、ジニ0.24、 $\Delta c_s / \delta = 0.963$ ）。この設定では普通のメンバーの予算は平均0.57あり、下限に当たる取引が無かった。 $\eta = 0.05$ は共謀が無くても $\Delta c_s / \delta$ を0.916へ下げる。

### P8 の上限との照合

P8（`farm_share_bound`）は、組 S の全員の予算が $\varepsilon$ 以上で、外の各人から S への $E'$ の流れが $\beta$ 以下なら

$$
\frac{c(S)}{N} \leq \frac{\beta}{\beta + \varepsilon \lvert S^c \rvert / (N-1)}
$$

を示す。150エポック後（自然回収の直後）の状態で、実際の共謀者の予算の最小値と実際の $\beta$ を入れて照合した。

| $\varepsilon$ | 共謀者の予算の最小 | $\beta$ | 占有 | 上限 | 上限（ $\beta = 1$ ） |
|---|---|---|---|---|---|
| 0.02 | 0.069 | 0.048 | 0.250 | 0.420 | 0.938 |
| 0.05 | 0.098 | 0.048 | 0.215 | 0.340 | 0.914 |
| 0.1 | 0.145 | 0.048 | 0.169 | 0.257 | 0.878 |
| 0.2 | 0.240 | 0.048 | 0.117 | 0.173 | 0.813 |

上限はいずれも成り立ち、実測の約1.5倍に収まっている。

## 分かったこと

### 1. ε は η と同じだけ link farm を抑え、副作用が小さい

$\varepsilon = 0.05$ と $\eta = 0.05$ の占有はほぼ同じ（0.34）だった。どちらも、共謀者の $E'$ の行から外へ同じくらいの量を漏らす仕組みだからである。違いは副作用で、 $\varepsilon$ は次の3点で優れていた。

- 定価の近似を悪くしない（ $\Delta c_s / \delta$ は0.969。 $\eta$ は0.922）
- 加入で既存メンバーの $c$ が動かない（P5 が厳密に残る）
- 共謀が無いときは何も変えない（この設定では一度も下限に当たらなかった）

加えて、全員の予算が正になるので P2 の前提が成り立ち、2組の共謀でも一意性エラーが出なかった（D4 のエラーが起きなくなる）。

### 2. どちらも link farm を「無くす」わけではない

$\varepsilon = 0.2$ でも、人口の5%の共謀者が貢献度の13%（人口比の約2.7倍）を持つ。理由は P8 の形にそのまま出ている。普通のメンバーは予算の社会的最低限を全員へ配るので、共謀者にも $\beta \approx E_{kk} \cdot 5/99$ が流れ込む。共謀者が外へ返すのは下限の $\varepsilon$ 分だけである。占有の上限は流入 $\beta$ と漏れ $\varepsilon \lvert S^c \rvert / (N-1)$ の比で決まり、 $\varepsilon$ を上げれば下がるが、 $\varepsilon$ を大きくすると使える予算が減る。

言い換えると、対策が無いとき（P7）は社会的最低限の流入だけで全部を吸い上げられたのに対し、 $\varepsilon$ があれば取り分は流入に比例する量に限られる。

### 3. 初期状態を変えても防げない

実験1（初期状態 $E = (1-m)I + mJ$ 、厳密モード）は途中までしか回せなかったが、 $m = 0.2$ でも占有は10/50/150エポック目で0.25 / 0.59 / 0.998と上がり、最後はほぼ吸収された。初期状態の評価は自然回収で $(1-\gamma)$ 倍ずつ消えるので、遅らせる効果しか無い。
