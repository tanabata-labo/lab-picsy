# 支払い1回あたりの計算コスト（2026-11-24）

参加者数 $N$ を100〜10000で振り、1回の支払いのあと貢献度 $c$ を計算し直す時間を測った。計測は12スレッドの手元の Windows 機（numpy の BLAS を使用）。再現は `cd python && uv run python scripts/bench_cost.py`。

## 方式

**密な直接法**（参照実装の `contributions`）: $(I - E')^\top$ の $N \times N$ の連立一次方程式を解く。計算量は $O(N^3)$ 、メモリは $O(N^2)$ 。

**構造を使った反復法**: $E'$ は「疎な評価」と「予算の均等配分」の和に分かれる。

$$
E' = E_{\mathrm{off}} + \frac{\mathrm{diag}(b)(\mathbf{1}\mathbf{1}^\top - I)}{N-1}
$$

$E_{\mathrm{off}}$ は対角を除いた評価、 $b$ は予算のベクトルである。すると

$$
c E' = c E_{\mathrm{off}} + \frac{(c \cdot b) \mathbf{1}^\top - c \circ b}{N-1}
$$

で、1回の積は $O(\mathrm{nnz} + N)$ （nnz は評価の非ゼロの数）で済む。この積を繰り返すべき乗法を、支払い直前の $c$ から始める（1回の支払いは $E$ の1行の2成分しか変えないので、直前の $c$ は良い初期値になる）。

決定 D3 はべき乗法を避けたが、それは $E'$ が周期的なときと、収束の速さに保証が無いときを嫌ったためである。D12（予算の下限 $\varepsilon$ ）のもとでは、全員の行から $\varepsilon/(N-1)$ 以上が全員へ流れるので、誤差は1回の反復でおおよそ $(1-\varepsilon)$ 倍以下に縮む。周期性も起きない。

## 結果

1人あたりの評価相手は50人（疎）とした。収束判定は $\max \lvert \Delta c \rvert < 10^{-12} N$ 。反復法の解と密な直接法の解の差は最大 $1.7 \times 10^{-10}$ だった。

| $N$ | 密な直接法 | メモリ | 反復法（ランダムな評価網） | 反復回数 | メモリ |
|---|---|---|---|---|---|
| 100 | 2〜22 ms | 0.2 MB | 0.2 ms | 8〜10 | 0.1 MB |
| 300 | 61〜112 ms | 1.4 MB | 0.3 ms | 8〜9 | 0.4 MB |
| 1000 | 約0.4 s | 16 MB | 0.5 ms | 7〜8 | 1.2 MB |
| 3000 | 0.5〜0.9 s | 144 MB | 1 ms | 6〜8 | 3.6 MB |
| 10000 | 約30 s（ $N^3$ で外挿） | 1.6 GB | 3〜4 ms | 6〜7 | 12 MB |

ランダムな評価網はよく混ざるので、反復が速いのは当然である。最悪に近い場合として、10人ずつの閉じた小集団に分かれ、集団の外へは予算の配分しか流れない評価網も測った（半数は予算に余裕があり、半数は下限ちょうど）。

| $\varepsilon$ | $N$ | 直前の $c$ から | 一様な $c$ から |
|---|---|---|---|
| 0.2 | 10000 | 17回・2.2 ms | 40回・4.3 ms |
| 0.1 | 10000 | 23回・2.9 ms | 59回・6.0 ms |
| 0.05 | 10000 | 25回・2.9 ms | 76回・7.4 ms |
| 0.02 | 10000 | 26回・4.4 ms | 90回・9.5 ms |

## 分かったこと

- 参照実装の密な直接法は $N = 1000$ で1回0.4秒、 $N = 10000$ で約30秒・1.6 GB になる。研究用には足りるが、支払いのたびに回す方式ではない
- $E'$ の構造（疎な評価＋予算の均等配分）を使えば、 $N = 10000$ でも1回の支払いは数ミリ秒・十数 MB で済む。1台のサーバで、1秒に数百件の支払いを捌ける
- 予算の下限 $\varepsilon$ は、link farm 対策（P8）と一意性（P2）に加えて、反復法の収束の速さも保証する。 $\varepsilon$ が無いと、予算を使い切った閉じた輪があるときに反復は収束しない（P7 の状況）
- 自然回収は全員の行を同時に変えるが、 $E_{\mathrm{off}} \leftarrow (1-\gamma) E_{\mathrm{off}}$ 、 $b \leftarrow (1-\gamma) b + \gamma \mathbf{1}$ と書けるので、これも $O(\mathrm{nnz} + N)$ で済む
- 評価は自然回収で $(1-\gamma)$ 倍ずつ減るだけで0にはならないので、放っておくと $E_{\mathrm{off}}$ は密になっていく。一定より小さい評価を予算へ戻して疎に保つ規則が要る（仕様の追加。I1・I2 は保てる）
