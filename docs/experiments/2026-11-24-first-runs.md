# 最初の比較実験（2026-11-24）

仕様 v0.1（[spec.md](../spec.md)）の参照実装で、n=100 の系を150エポック回した。調べたのは、論文どおりの貢献度計算（厳密モード、 $\eta = 0$ ）と PageRank 型の正則化（ $\eta > 0$ 、決定 D4）の差、および共謀（link farm）への強さである。

## 設定

- 初期状態は $E = I$ （D11）。1エポック = 取引100回のあと自然回収1回（ $\gamma = 0.05$ ）
- 買い手は一様に選ぶ。売り手は人気の偏り（Zipf、指数1）に比例して選ぶ。定価 $\delta$ は売り手ごとに固定（平均0.02、対数正規）で、 $\alpha = \delta / c_b$ に換算する（D6）。予算を超える取引は拒否する（D5）
- link farm: 共謀者が毎エポックの最初に予算を全額、組の仲間へ払う。共謀者は普通の取引には加わらない
- 再現: `cd python && uv run python scripts/run_first.py 150`。各エポックの記録は `runs/first/*.csv`（git 対象外）

数値は最後の10エポックの平均。「farm 占有」は共謀者の貢献度の合計を $N$ で割ったもの（最大値／最後の平均）。

## 分かったこと

### 1. 共謀が無ければ、論文どおりの計算で破綻しない

通常のシナリオでは、不変条件は保たれた。 $c$ は0.66〜5.97の範囲に収まり、拒否も一意性エラーも起きなかった。

- 表3.2の「取引で買い手の貢献度は変わらない」は近似だが、ずれは最大 $1.8 \times 10^{-3}$ と小さい
- 定価 $\delta = \alpha c_b$ も近似で、売り手の貢献度が実際に増えるのは $\delta$ の約96%だった（ $N=6$ のときは約7割）。 $N$ が大きいほど近似は良くなる
- $E'$ の第2固有値は0.2程度で、 $c$ の計算は良条件

### 2. 厳密モードは link farm に弱い

論文 5.1節は「予算制約があるので、SEO の link farm のような不正は難しい」と述べている。この設定では逆の結果になった。

- 5人（人口の5%）が初日から予算を仲間内に払い続けると、 $c$ の100%が5人に集まった。残る95人は $c = 0$ になり、 $\alpha = \delta / c_b$ が無限大になるので何も買えない。経済は止まる
- 50エポック普通に取引してから共謀を始めても、100エポックで占有は87%まで上がった。共謀者が以前に外へ付けた評価は、自然回収のたびに $(1-\gamma)$ 倍に減って消えていくので、いずれ共謀者だけの閉じた輪になる
- 共謀が2組あると閉じたクラスが2つになり、D4 のとおり一意性エラーで止まった

仕組みはこうである。予算を使い切った人の $E'$ の行は $E$ の行と同じになり、社会的最低限 $E_{ii}/(N-1)$ を他人へ配らない。一方、普通のメンバーは予算の一部を全員へ配るので、その一部は共謀者にも流れ込む。共謀者からは外へ何も出ていかない。共謀者の組は、価値が流れ込むだけで出ていかない吸収集合になる。

### 3. 正則化（ $\eta > 0$ ）は経済を止めないが、ただではない

- $\eta = 0.05$ では、どのシナリオでも取引の大半が成立した。共謀者の占有は約34%（人口比の約7倍）に抑えられた。抑えられたが、ゼロにはなっていない
- 代わりに、定価の近似が悪くなる（ $\Delta c_s / \delta$ が0.96から0.92へ）。売り手の受け取る価値の一部が、全員への一様な配分に回るためである
- 共謀が無いときの差は小さい（ジニ係数0.24 → 0.23）

## 未確認のこと（次の実験）

- 正則化モードで、加入（(3.69)）が既存メンバーの $c$ を保つか。性質 P5 は $E'$ の固定点についての主張なので、 $\eta > 0$ では厳密には崩れるはずで、崩れ方の大きさを測る
- 初期状態を $E = I$ 以外（たとえば全員が全員を少しずつ評価した状態）にすると、初日からの共謀が効かなくなるか
- 正則化を使わずに link farm を抑える方法があるか（例: 予算を使い切った人にも最低限の配分を課す。仕様の変更になる）
- 加入・離脱（凍結→除去）を混ぜたシナリオ。 $\gamma$ と取引頻度の比を変えたとき
