# はじめに

PICSY（Propagational Investment Currency SYstem、伝播投資貨幣）は、鈴木健さんが2000年代に提案した貨幣の仕組みです。お金を払うと、そのお金が手を離れて終わるのではなく、「払った相手への評価」として残ります。評価された人がさらに誰かを評価すると、その評価が連鎖して伝わっていきます。誰がどれだけ社会に貢献しているかを、評価の連鎖から計算するのが PICSY の中心にある考え方です。一般向けには『なめらかな社会とその敵』（勁草書房 2013、筑摩書房版 2022）で知られています。

七夕研究所では社内の小さな研究として、PICSY を実際に動かせる形にしてみました。この連載で書くのは次の3つです。

1. 論文を仕様に落とし、Lean で性質を証明する（この記事）
2. シミュレーションで壊して、直す。論文には「予算の制約があるので、検索エンジンの link farm のような不正は難しい」と書かれています。実際に動かすと、この主張は成り立ちませんでした。少人数の共謀で、全員の貢献度を吸い上げられます。その理由を定理として示し、論文の定義を変えずに直す方法を提案します
3. 社会実装のハードル。計算コスト、法と制度、取引の取り消し

この記事は地道な仕様化の回です。ただ、2回目の「壊れる」話は、ここで決めた仕様を前提にしています。

コード・仕様書・証明は、すべて次の GitHub リポジトリに置いています。

https://github.com/tanabata-labo/lab-picsy

# PICSY の仕組み

## 一次資料

正本は鈴木さんの博士論文です。

> Ken Suzuki, *Propagational Investment Currency SYstem (PICSY): Proposing a New Currency System Using Social Computing*, 博士論文, 東京大学大学院総合文化研究科, 2009.

調べた範囲では、この博士論文の本文をオンラインで読める公開版は見つかりませんでした（国立国会図書館の所蔵は紙のみ）。この連載では式番号で参照します。同じ方式の式は、人工知能学会全国大会の2頁の論文でも読めます。

> 鈴木健「伝播投資貨幣PICSY」人工知能学会全国大会論文集 JSAI2009, 3E3-NFC2-10. https://doi.org/10.11517/pjsai.jsai2009.0_3e3nfc210

なお、PICSY には IPA 未踏ソフトウェア創造事業（2002年度）で作られた Java のデモ実装があります。一方で、論文の数理を第三者が実装して検証した例は、日本語でも英語でも見つかりませんでした。

## 評価行列と予算

参加者を $N$ 人とします。状態は $N \times N$ の評価行列 $E$ だけです。成分 $E_{ij}$ は「 $i$ が $j$ をどれだけ評価しているか」を表し、各行の和は1です。

```math
E_{ij} \geq 0, \qquad \sum_j E_{ij} = 1
```

対角成分 $E_{ii}$ は特別で、まだ誰にも付けていない評価の残り、つまり $i$ の**予算**です。

**取引**は、買い手 $b$ が予算から $\alpha$ を取り出して、売り手 $s$ への評価に付け替える操作です。

```math
E_{bb} \leftarrow E_{bb} - \alpha, \qquad E_{bs} \leftarrow E_{bs} + \alpha
```

普通のお金との一番の違いは、お金が手から手へ移らない点です。取引では、買い手の行の中で予算が評価に変わるだけです。

**自然回収**は、全員の評価を少しずつ予算へ戻す操作です。回収率を $\gamma$ として

```math
E \leftarrow (1-\gamma) E + \gamma I
```

を全員に同時にかけます。この操作で昔の評価はだんだん小さくなり、その分が予算に戻ります。

## 貢献度は評価の連鎖の定常分布

貢献度 $c$ は、評価の連鎖を無限にたどったときの定常分布です。ただし、予算 $E_{ii}$ をそのまま自分への評価として扱うと、予算を貯め込む人に価値がたまってしまいます。論文はいくつかの方式を比べ、**仮想中央銀行法**を最良としています。各人の予算を、自分以外の $N-1$ 人へ均等に配った行列 $E'$ を作る方式です。

```math
E'_{ii} = 0, \qquad E'_{ij} = E_{ij} + \frac{E_{ii}}{N-1} \quad (i \neq j)
```

論文はこの均等配分を「社会的最低限（social minimum）」と呼んでいます。貢献度 $c$ は

```math
c E' = c, \qquad c_i \geq 0, \qquad \sum_i c_i = N
```

を満たす行ベクトルです。PageRank とほぼ同じ形をしています。買い物に使える力（購買力）は $E_{bb} c_b$ で、予算の割合に、自分の貢献度を掛けたものです。

予算と貢献度は別の量です。予算は自分の行の対角で、自然回収でしか増えません。貢献度は他人からの評価で決まり、売ると上がります。この違いは、2回目と3回目の議論で重要になります。

# 論文を仕様に落とす

論文の定義をそのまま実装しようとすると、決まっていない箇所がいくつも出てきます。仕様書では、決めた箇所を「決定 D*n*」として理由と一緒に書きました。主なものを挙げます。

| 決定 | 論文に無かったこと | 決めた内容 |
|---|---|---|
| D3 | $c$ の計算法 | べき乗法は使わず、連立一次方程式 $c(I - E') = 0$ 、 $\sum c_i = N$ を解く。べき乗法は $E'$ が周期的なとき収束せず、収束判定の閾値も要るため |
| D4 | $c$ が一意に決まらないとき | 論文 (3.4) はペロン＝フロベニウスの定理で「解がある」と言うだけで、一意性に触れていない。一意でなければエラーにする（厳密モード）。比較用に PageRank 型の正則化モードも用意する |
| D5 | 予算を超える取引 | $\alpha \leq E_{bb}$ は文としてあるだけで、式に無い。これが無いと非負性が崩れるので、満たさない取引は拒否する |
| D6 | 価格の単位 | 取引の入力は $\alpha$ （評価の単位）とする。定価 $\delta$ で指定するときは $\alpha = \delta / c_b$ に換算する。これは論文の近似式で、実際の $c_s$ の増え方とのずれを測る |
| D9 | 離脱 | 論文は「中央銀行法と同じ手順」とだけ書き、行列からどう行と列を取り除くかを定義していない。凍結→除去の2段階にし、他人が離脱者に付けていた評価は本人の予算へ戻す |
| D11 | 初期状態 | 論文に見当たらない。 $E = I$ （全員が予算1）から始める |

ほかに、論文の式で読み方に注意が要る箇所も記録しました。たとえば表3.2は「取引で買い手の貢献度は変わらない」としていますが、これは近似です。売り手から買い手へ戻る評価の流れがあると、厳密には動きます。定価の式 $\delta = \alpha c_b$ も同じ近似に依っていて、 $N=6$ の乱数例では、売り手の貢献度が実際に増えたのは $\delta$ の約7割でした（ $N = 100$ では約96%）。

仕様書の全体は [docs/spec.md](https://github.com/tanabata-labo/lab-picsy/blob/main/docs/spec.md) にあります。

# Lean で性質を証明する

仕様を決めたあと、守られるべき性質を Lean 4 + Mathlib で証明しました。状態は有理数の行列として持ちます。

```lean
/-- 評価行列。Mathlib の `Matrix` ではなく素の関数型で持つ（成分の計算しかしないため）。 -/
abbrev Mat (n : Type*) := n → n → ℚ

/-- 不変条件 I1（非負）と I2（行和1）。 -/
def IsStochastic (E : Mat n) : Prop :=
  (∀ i j, 0 ≤ E i j) ∧ ∀ i, ∑ j, E i j = 1

/-- 仮想中央銀行を配った行列 E'（論文 (3.63)）。 -/
def vcb (E : Mat n) : Mat n :=
  fun i j => if i = j then 0 else E i j + E i i / (Fintype.card n - 1)
```

`n` は参加者を表す有限型です。最初は Mathlib の `Matrix` 型を使いましたが、関数として適用したときの展開がうまく進まなかったので、素の関数型にしました。

import も工夫しました。`import Mathlib` で全体を読み込むとビルドに20分以上かかったので、必要なモジュールだけを import して約10秒に縮めました。

この記事の範囲で証明した性質は次のとおりです。

| 性質 | 内容 | 定理 |
|---|---|---|
| P1 | 不変条件のもとで、 $E'$ は非負・行和1・対角0 | `vcb_stochastic` |
| P3 | 取引は、D5 の前提のもとで不変条件を保つ | `transact_stochastic` |
| P4 | 自然回収は不変条件を保ち、全員の予算を $\gamma$ 以上にする。さらに $E'$ を $(1-\gamma)E' + \gamma J$ に写す（ $J$ は全員が全員を均等に評価する行列） | `recover_stochastic`, `vcb_recover` |
| P5 | 加入（論文 (3.69)）は不変条件を保ち、既存メンバーの貢献度を変えない | `join_stochastic`, `join_fixed_point` |
| P6 | 離脱者の除去（D9）は不変条件を保つ | `remove_stochastic` |
| P2 | 全員の予算が正なら、貢献度はただ1つに決まる | `contributions_unique` |

## P5: 加入は既存メンバーの貢献度を変えない

PICSY では、人が増えることが唯一の「通貨の発行」です。新メンバーは貢献度1・予算0で加わり、既存メンバーの貢献度と予算は変わりません。論文はこれを数値例で示していますが、証明はしていません。

Lean では、新メンバーを `none`、既存メンバー `i` を `some i` とする `Option n` 型の上で加入後の行列を定義しました。そのうえで「加入前の固定点 $c$ に1を付け足したベクトルが、加入後も固定点になる」ことを示しています。

## P2: 一意性を、ペロン＝フロベニウスなしで示す

D4 で書いたとおり、論文は貢献度の一意性に触れていません。この一意性の問題が、2回目の話につながります。

一意性の証明には、ふつうはペロン＝フロベニウスの定理を使います。Mathlib で既約な行列についてこの定理がどこまで整っているかを調べる代わりに、もっと初等的な**流れの収支**で示しました。行和1の行列 $M$ と定常なベクトル $c$ について、どんな組 $S$ をとっても、 $S$ から外へ流れ出る量と、外から $S$ へ流れ込む量は等しくなります。

```lean
theorem flow_balance (M : Mat n) (hM : ∀ i, ∑ j, M i j = 1) (S : Finset n) (c : n → ℚ)
    (hc : ∀ j, ∑ i, c i * M i j = c j) :
    ∑ k ∈ S, c k * ∑ j ∈ Sᶜ, M k j = ∑ k ∈ Sᶜ, c k * ∑ j ∈ S, M k j
```

この等式に $c$ の非負性は要りません。一意性はこの等式から導けます。2つの解の差を $d$ とすると、 $d$ も定常で、成分の和は0です。 $d$ が正の人の組を $S$ とすると、 $S$ から外への流れは0以上、外から $S$ への流れは0以下なので、どちらも0になります。ところが全員の予算が正なら $E'$ の非対角はすべて正なので、 $S$ が空でも全体でもない限り、 $S$ から外への流れは正になるはずです。この矛盾から $d \leq 0$ が言えます。 $-d$ にも同じ議論を適用すると $d = 0$ となり、2つの解は一致します。

系として、自然回収の直後は全員の予算が $\gamma$ 以上なので、貢献度はいつも一意です。一意性が崩れうるのは、自然回収と自然回収のあいだに、予算を使い切った人が出たときだけです。

逆に言えば、予算を使い切った人たちが外を一切評価しない閉じた輪を作ると、一意性も、それ以上のものも成り立たなくなります。2回目はこの話をします。

# 参照実装と性質テスト

Python の参照実装（`picsy.core`）は、浮動小数と有理数（`fractions.Fraction`）の両方で動くようにしました。性質テストは hypothesis で乱数の評価行列を作り、P1〜P6 を有理数で厳密に確かめます。有理数なら等号の判定に誤差の閾値を使わずに済むので、「近似的に成り立つ」と「厳密に成り立つ」を区別できます。表3.2の「買い手の貢献度は変わらない」が近似だと分かったのも、この区別のおかげです。

```python
@given(eval_matrix(positive_budget=True))
def test_P5_join_keeps_contributions_and_budgets(E):
    n = len(E)
    c = contributions(E)                  # 有理数で厳密に解く
    assert sum(c) == n
    E2 = join(State(E), c).E
    assert is_stochastic(E2)
    assert all(E2[i, i] == E[i, i] for i in range(n)) and E2[n, n] == 0
    c2 = contributions(E2)
    assert list(c2) == list(c) + [1]      # 既存メンバーは不変、新メンバーは1
```

# まとめと次回

論文の定義を仕様に落とすために、D1〜D11 の11の決定を置きました。そのうえで、不変条件・加入・離脱・一意性などの性質を Lean で証明しました。

次回は、この仕様で n=100 の経済を動かします。共謀がなければ、論文どおりに計算して何も問題は起きません。ところが、5人が予算を仲間内だけに払い続けると、残り95人の貢献度が0になり、経済が止まります。論文5.1節の「予算の制約があるので link farm は難しい」とは逆の結果です。なぜそうなるのかを定理として示し、論文の定義を変えずに直す方法を提案します。
