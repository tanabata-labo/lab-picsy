# はじめに

[前回](./01-spec-and-lean.md) は、鈴木健さんの伝播投資貨幣 PICSY を仕様に落とし、性質を Lean で証明しました。今回はその仕様で、n=100 の経済を動かします。

PICSY の博士論文の5.1節には、次の一文があります。

> However, because budget constraints exist in PICSY, an SEO-like cheat would be difficult.
> （PICSY には予算の制約があるので、SEO のような不正は難しいだろう）

ここで言う SEO の不正とは、link farm のことです。サイトどうしで互いにリンクを張り合い、PageRank を吸い上げる手口を指します。PICSY の貢献度も PageRank と同じく評価の連鎖の定常分布なので、同じ手口が効くかどうかは自然な疑問です。論文は「予算の制約」があるので難しいと見ています。

結論から書くと、この主張は成り立ちませんでした。人口の5%の共謀者が予算を仲間内だけに払い続けると、残り95%の貢献度が0になり、経済が止まります。この記事では、

1. シミュレーションで壊れる様子を見る
2. なぜ壊れるのかを定理（P7）として示す
3. 論文の貢献度の定義を変えない直し方（予算の下限 ε）を提案し、効き目の上限を定理（P8）として示す

の順に進めます。記号は前回と同じです。評価行列 $E$ の対角 $E_{ii}$ が予算で、仮想中央銀行法では予算を他の $N-1$ 人へ均等に配った行列 $E'$ から、貢献度 $c$ （ $cE' = c$ 、 $\sum c_i = N$ ）を計算します。

# シミュレーションの設定

- 参加者 $N = 100$ 、初期状態は $E = I$ （全員が予算1）
- 1エポック = 取引100回のあと、自然回収1回（回収率 $\gamma = 0.05$ ）
- 買い手は一様に選ぶ。売り手は人気の偏り（Zipf 分布、指数1）に比例して選ぶ
- 定価 $\delta$ は売り手ごとに固定（平均0.02、対数正規分布）。取引の量は $\alpha = \delta / c_b$ に換算し、予算を超える取引は拒否する
- 150エポック（約1万5千取引）回す

共謀者（link farm）は、毎エポックの最初に予算を全額、組の仲間へ払います。普通の取引には加わりません。

# 共謀が無ければ、論文どおりの計算で問題なく動きます

まず共謀の無い経済です。150エポック回しても、問題は何も起きませんでした。

取引はほぼすべて成立し（1エポック99.5件、拒否0）、貢献度は0.66〜5.97の範囲に収まりました。ジニ係数は0.24です。浮動小数の誤差も積み上がらず、行和の誤差は $1.3 \times 10^{-15}$ 以下にとどまりました。 $E'$ の第2固有値の絶対値は0.2程度なので、貢献度の計算は良条件です。前回触れた定価の近似は、 $N = 100$ では約96%の精度でした。ここでの精度は、売り手の貢献度が実際に増えた量を定価で割った値です。

# 5人が共謀すると、経済が止まります

次に、100人のうち5人が初日から共謀します。

| シナリオ | 共謀者の貢献度の占有 | 成立した取引/エポック | 貢献度の最小〜最大 |
|---|---|---|---|
| 共謀なし | — | 99.5 | 0.66〜5.97 |
| 5人が初日から共謀 | **100%** | **0** | 0.00〜20.0 |
| 5人が50エポック目から共謀 | 87% | 32.3 | 0.05〜17.3 |
| 5人ずつ2組が初日から共謀 | 計算できない | 0 | — |

5人が初日から共謀すると、貢献度の100%が5人に集まりました。残る95人は貢献度0です。購買力は「予算 × 貢献度」なので、95人は誰も何も買えなくなり、経済が止まります。50エポックのあいだ普通に取引してから共謀を始めても、100エポック後には87%まで吸い上げられました。共謀が2組あると、貢献度がただ1つに決まらなくなり、計算そのものが止まります。

初期状態を「全員が全員を少しずつ評価し合っている状態」に変えても防げませんでした。初期状態の評価の割合を0.2にすると、占有は10エポック目で25%、50エポック目で59%、150エポック目で99.8%と、遅れるだけでした。初期状態の評価も、自然回収で $(1-\gamma)$ 倍ずつ消えていくためです。

# 経済が止まる理由（P7）

仕組みは単純です。普通のメンバーは予算の一部を持っていて、それは $E'$ の上で全員へ均等に配られます。共謀者にも流れ込みます。一方、予算を使い切った共謀者の $E'$ の行は、 $E$ の行と同じです。社会的最低限 $E_{ii}/(N-1)$ が0なので、他人へ何も配りません。共謀者どうしでしか評価し合っていないので、組の外へは何も流れ出ません。

価値が流れ込むだけで出ていかない組は、マルコフ連鎖の**吸収集合**です。定常分布では、組の外の全員が0になります。これを Lean で証明しました。

```lean
/-- P7: 予算0で組の外を評価しない組 S があれば、
    組の外で予算が正の人の貢献度は0になる。 -/
theorem farm_absorbs (hN : 2 ≤ Fintype.card n) (E : Mat n) (hE : IsStochastic E)
    (S : Finset n) (hS : S.Nonempty)
    (hbroke : ∀ i ∈ S, E i i = 0) (hclosed : ∀ i ∈ S, ∀ j ∉ S, E i j = 0)
    (c : n → ℚ) (hc0 : ∀ i, 0 ≤ c i) (hc : ∀ j, ∑ i, c i * vcb E i j = c j)
    (i : n) (hi : i ∉ S) (hbudget : 0 < E i i) : c i = 0
```

証明には、前回 P2 の一意性で使った流れの収支を使います。定常な $c$ では、組 $S$ から外へ流れ出る量と、外から $S$ へ流れ込む量が等しくなります。 $S$ から外への流れは0なので、外から $S$ への流れも0でなければなりません。ところが組の外で予算が正の人は、社会的最低限として必ず $S$ へ正の量を流しています。両立するには、その人の貢献度が0であるしかありません。

論文の言う「予算の制約」は、各人が評価に使える量の上限です。ただ、上限があっても、上限まで仲間内に使い切ることは止められません。使い切った人は社会的最低限を出さなくなるので、かえって吸収集合を作りやすくなります。

なお、P7 は「完全に閉じた組ができあがった状態」についての定理です。共謀者が以前に外へ付けた評価は、自然回収のたびに $(1-\gamma)$ 倍になるだけで、厳密には0になりません。そこへ近づいていく様子は、上のシミュレーションで見たものです。

# 直し方: PageRank 型の正則化と、予算の下限

P7 の対偶から、経済が止まらないための条件ははっきりしています。どの組も、外へ一切価値を出さない状態にならないことです。この条件を仕組みに入れる方法は2通り考えられます。

**η 正則化**: 貢献度を計算するときだけ、 $E'$ の代わりに $(1-\eta)E' + \eta J$ を使います（ $J$ は全員が全員を均等に評価する行列）。PageRank の減衰係数（ランダムジャンプ）と同じ形です。全員の行から $\eta$ が全員へ流れるので、吸収集合はできません。ただし、論文の貢献度の定義そのものを変えます。

**予算の下限 ε**: 取引のルールを「予算を $\varepsilon$ 未満まで使ってはいけない」に締めます。

```math
0 < \alpha \leq E_{bb} - \varepsilon
```

予算が残っている限り、その人は $E'$ の上で全員へ $E_{ii}/(N-1)$ ずつを配ります。全員の予算が $\varepsilon$ 以上なら、どの組からも外へ必ず価値が漏れるので、P7 の前提が崩れます。論文の貢献度の定義は変えず、取引の上限だけを変える方法です。

## 比べてみる

同じ「5人が初日から共謀」のシナリオで比べました（150エポック、最後の10エポックの平均）。

| 対策 | 共謀者の占有 | 成立した取引/エポック | 定価の精度 | 加入で既存メンバーの貢献度が動く量 |
|---|---|---|---|---|
| なし（論文どおり） | 100% | 0 | — | 0 |
| η = 0.05 | 34% | 94.6 | 92% | 最大 $2 \times 10^{-3}$ |
| **ε = 0.05** | **34%** | 92.7 | **97%** | **0** |
| ε = 0.1 | 22% | 97.3 | 97% | 0 |
| ε = 0.2 | 13% | 98.3 | 96% | 0 |

同じ大きさの $\eta$ と $\varepsilon$ は、共謀者の占有をほぼ同じだけ抑えました。どちらも、共謀者の行から外へ同じくらいの量を漏らす仕組みだからです。違いは副作用に出ました。

1つ目の違いは定価の精度です。 $\eta$ は売り手が受け取る価値の一部を全員への一様な配分に回すので、精度が96%から92%に落ちます。 $\varepsilon$ は精度を落としません。

2つ目は加入です。前回の P5（加入で既存メンバーの貢献度が変わらない）は、 $E'$ の固定点についての定理です。 $\eta$ は貢献度の定義を変えるので P5 が崩れ、既存メンバーの貢献度は $\eta$ と経過時間に比例してずれます。 $\varepsilon$ は定義を変えないので、P5 がそのまま成り立ちます。

3つ目は共謀が無いときの振る舞いです。この設定では普通のメンバーの予算は平均0.57あり、 $\varepsilon = 0.2$ でも一度も下限に当たりませんでした。そのため結果は $\varepsilon$ を入れないときと完全に同じでした。一方 $\eta$ は、共謀が無くても定価の精度を下げます。

加えて、 $\varepsilon$ を入れると全員の予算が正になるので、P2（一意性）の前提がいつも成り立ちます。2組の共謀でも、計算は止まらなくなりました。

## 下限の効果には上限があります（P8）

予算の下限を入れたとき、共謀した組がどこまで取れるかを定理にしました。

```lean
/-- P8: 組 S の全員の予算が ε 以上で、外の各人から S への E' の流れが β 以下なら、
    c(S) · (ε|Sᶜ|/(N-1) + β) ≤ β·N -/
theorem farm_share_bound (hN : 2 ≤ Fintype.card n) (E : Mat n) (hE : IsStochastic E)
    (S : Finset n) (ε β : ℚ) (hfloor : ∀ i ∈ S, ε ≤ E i i)
    (hinflow : ∀ k ∉ S, ∑ j ∈ S, vcb E k j ≤ β)
    (c : n → ℚ) (hc0 : ∀ i, 0 ≤ c i) (hc : ∀ j, ∑ i, c i * vcb E i j = c j)
    (hsum : ∑ i, c i = Fintype.card n) :
    (∑ i ∈ S, c i) * (ε * (Sᶜ.card : ℚ) / (Fintype.card n - 1) + β)
      ≤ β * Fintype.card n
```

占有率の形に直すと

```math
\frac{c(S)}{N} \leq \frac{\beta}{\beta + \varepsilon \lvert S^c \rvert / (N-1)}
```

です。証明はここでも流れの収支です。組の全員の予算が $\varepsilon$ 以上なら、組の各人の $E'$ の行から、外へ少なくとも $\varepsilon \lvert S^c \rvert / (N-1)$ が漏れます。外から組への流れは $\beta$ 以下です。流れ出る量と流れ込む量が等しいことから、上の不等式が出ます。 $\beta \leq 1$ はいつも成り立つので、上限は必ずあります。

シミュレーションの最終状態に、実際に測った $\beta$ を入れて照合しました。

| ε | 実測の占有 | P8 の上限 |
|---|---|---|
| 0.02 | 25.0% | 42.0% |
| 0.05 | 21.5% | 34.0% |
| 0.1 | 16.9% | 25.7% |
| 0.2 | 11.7% | 17.3% |

どの場合も上限の内側にあり、上限は実測の約1.5倍でした（この表は自然回収の直後の状態なので、上の比較表の値とは少し違います）。

## 共謀は無くせず、取り分を抑えられるだけです

注意が要るのは、下限を入れても link farm は無くならないことです。 $\varepsilon = 0.2$ でも、人口の5%の共謀者が13%を持っています。理由は P8 の形にそのまま出ています。普通のメンバーは予算の社会的最低限を全員へ配るので、共謀者にも流入 $\beta$ が入ります。それに対して共謀者が外へ返すのは、下限の $\varepsilon$ の分だけです。

P7 と P8 を並べると、対策の有無で次のように違います。対策が無ければ（P7）、社会的最低限が流れ込むだけで、共謀者の組が全部を吸い上げられます。予算の下限を入れると（P8）、共謀者の取り分は、外からの流入 $\beta$ と強制的な漏れ $\varepsilon$ の比で決まる量に限られます。

$\varepsilon$ を上げれば取り分は下がりますが、そのぶん誰もが使える予算が減ります。どこで釣り合わせるかは、制度設計の問題です。

## 新メンバーへの影響

下限があると、新メンバーは不利にならないでしょうか。新メンバーは予算0で加わり、予算は自然回収でしか戻りません（売って増えるのは貢献度です）。共謀の無い経済を100エポック回してから1人加え、その後60エポック追いました。

$\varepsilon$ の影響が出るのは加入後10エポックほどだけでした。最初の買い物は2エポック目から6〜7エポック目に遅れますが、30エポック目にはどの $\varepsilon$ でも差がほぼ消えます。

新メンバーが既存メンバーの購買力の中央値に追いつけるかを決めたのは、 $\varepsilon$ ではなく売り手としての人気でした。人気上位は11〜17エポックで中央値を超え、中位以下は60エポックたっても中央値の4〜9割にとどまりました。

# 先行研究との関係

ここまでの数学は、実は新しいものではありません。

- 吸収（P7）: 閉じた組が吸収集合になるのは、マルコフ連鎖の標準的な事実です。Bianchini らは PageRank で、減衰を入れないと外へリンクを持たない組が有利になり続けることを論じています。EigenTrust の論文も、事前に信頼されたピアが無いと、共謀集団に入ったランダムな歩みが抜け出せないと述べています
- 上限（P8）: 「強制的な流出の下限」と「流入 = 流出」で共謀した組を抑える論法は、Zhang らが固有ベクトル型の評判システムで使っています（共謀による増幅は $O(1/\varepsilon)$ ）。Bianchini らの「エネルギー収支」も同じ形の上限です
- η 正則化: PageRank のランダムジャンプ、EigenTrust の事前に信頼されたピアと同じ形です

この記事の新しさは、これらを PICSY の仮想中央銀行法に当てはめた点にあります。予算を使い切るという PICSY に固有の行動が吸収集合を生み、論文5.1節の主張が成り立たなくなることを示しました。そのうえで、貢献度の定義を変えない対策（予算の下限）を設計し、η 正則化と副作用を比べました。調べた範囲では、PICSY の数理を第三者が分析した文献は、日本語でも英語でも見つかりませんでした。

# まとめと次回

- 論文5.1節の「予算の制約があるので link farm は難しい」は成り立ちません。予算を使い切って仲間内だけを評価する組は吸収集合になり、組の外の貢献度は0になります（P7）
- 取引で予算を $\varepsilon$ 未満に下げられないルールを入れると、組の取り分に上限が付きます（P8）。論文の貢献度の定義を変えないので、PageRank 型の正則化より副作用が小さく済みます
- ただし共謀は無くならず、取り分が流入に比例する量へ抑えられるだけです

次回は、PICSY を実際に社会で動かすときのハードルを考えます。参加者1万人でも1回の支払いの計算は数ミリ秒で済むこと、日本円と交換しない場合でも残る法的・制度的な論点、そして取引の取り消しを仕様と証明に落とす話です。
